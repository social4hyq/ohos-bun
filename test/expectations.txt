# --- js/node/cluster: process.send()/process.disconnect() IPC race, pre-existing ---
# Every worker forked calls process.send("hello") immediately followed by
# server.close()+process.disconnect() in the same tick; disconnect() appears
# to race the queued IPC write and can drop the message before it's flushed,
# so the primary's `workers` counter under-counts (varies run to run: 8-13
# of N workers actually get counted, though all N do cluster.on("exit")
# cleanly — the workers aren't lost, just their "hello" message is).
# Reproduces byte-for-byte on the installed production bun (1.4.2+744846f84,
# the 106-patch series) with the same "N !== numCPUs" shape — confirmed via
# `/storage/Users/currentUser/.harmonybrew/bin/bun test-docs-http-server.ts`
# directly, 2026-09-14. Pre-existing on both old and new builds, not
# OHOS-specific and not caused by any change in this branch — out of scope
# for this porting effort (same class as test-child-process-cwd.js above).
